Démarrer avec EstimLink

Un seul programme installe tout. Une solution NGNIOR CONCEPTION.

1. Installer EstimLink pour Windows

Téléchargez et lancez EstimLink-Setup-2.0.0.exe (environ 58 Mo). Il installe le complément Excel et l’agent local qui enregistre vos projets sur votre poste. Windows (UAC) vous demandera une confirmation.

⬇ Télécharger EstimLink-Setup-2.0.0.exe

  1. Fermez Excel et Archicad, puis lancez l'installeur et suivez les étapes.
  2. L'agent démarre automatiquement et se relancera à chaque ouverture de session Windows.
  3. Dans Excel : Insertion → Mes compléments → Dossier partagé → Estim Link → Ajouter (une seule fois ; ensuite l'onglet reste disponible).

Vous aviez déjà EstimLink ? Lancez simplement ce programme : il met à jour l'installation et conserve vos projets.

2. Liaison Archicad (automatique)

Si Archicad 27, 28 ou 29 est présent sur votre poste, l'installeur ajoute l'add-on Tapir (open source, licence MIT) dans chaque version détectée. Sans Archicad, rien n'est ajouté et EstimLink fonctionne normalement.

  1. Relancez Archicad après l'installation.
  2. Vérifiez que Tapir est chargé dans Options → Gestionnaire d'extensions.
  3. Archicad installé plus tard ? Relancez l'installeur EstimLink pour ajouter Tapir.

Le chargement manuel du manifeste dépend de votre version d’Excel et des autorisations de votre organisation. Si l’option est absente, rapprochez-vous de votre administrateur.

3. Installer dans Excel sur le web (alternative sans installeur)

  1. Téléchargez le manifeste seul (EstimLink-manifest.xml).
  2. Ouvrez un classeur sur excel.office.com (ou office.com → Excel).
  3. Onglet Accueil → Compléments → Plus de compléments.
  4. Onglet Mes compléments → Charger mon complément (Upload My Add-in).
  5. Sélectionnez le fichier téléchargé, puis validez : l'onglet Estim Link apparaît dans le ruban.

4. Compte et enregistrement

Dans la version publiée, utilisez les options de connexion proposées par votre volet. Dans la v2 en validation, le travail local est accessible sans compte. Installez et démarrez l’agent compatible v2 avant de travailler : vérifiez le statut « Enregistré ». Un agent ancien ou injoignable ne permet pas l’enregistrement des projets v2.

5. Premiers pas dans la v2 en validation

  1. Dans Excel, utilisez les palettes Titre / Total / Recap / RecapG pour construire vos lots et récapitulatifs.
  2. Organisez les feuilles de quantités et leurs formules reliées. Recherchez vos prix dans votre bibliothèque ou dans Mercurial, puis choisissez Min, Moy ou Max.
  3. Vérifiez l’enregistrement dans l’agent local. Utilisez le partage .estimlink pour transmettre les éléments souhaités à un collègue.

La v2 ne comporte pas de chat intégré au volet. Son serveur MCP se configure séparément avec un agent IA externe compatible.

6. Connecter ArchiCAD

Le connecteur ArchiCAD (étape 2) doit être installé, et Archicad ouvert avec votre projet. Depuis l'onglet ArchiCAD du panneau, chargez votre maquette : EstimLink résout les références de la maquette pour injecter les quantités du modèle dans vos postes.
