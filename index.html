Exportez et importez des tables, feuilles ou paramètres au format .estimlink pour les transmettre à un collègue.

05 — TRAVAILLER

Un usage local sans compte

Le travail local de la v2 ne nécessite pas de compte. Un agent local compatible v2 doit être installé et démarré pour enregistrer vos projets, même sans Archicad.

06 — CONNECTER

Vos agents IA, en option

Connectez un agent IA externe compatible via le serveur MCP. Cette configuration est optionnelle : les outils de métré et de chiffrage s’utilisent directement dans le complément.

LES RÉPONSES ESSENTIELLES

Avant de commencer.

Faut-il installer Archicad pour utiliser EstimLink ?

Non. La liaison Archicad est optionnelle. En v2, l’agent local compatible reste nécessaire pour enregistrer les projets, même lorsque vous travaillez sans maquette Archicad.

Comment installer le complément ?

Sous Windows, téléchargez l’installateur EstimLink et suivez le guide pas à pas. Pour Excel sur le web, utilisez le manifeste si votre organisation autorise le chargement de compléments.

J’ai déjà EstimLink : comment mettre à jour ?

Lancez le nouvel installateur. Il met à jour le complément et l’agent local, et conserve vos projets.

Faut-il un compte pour travailler en v2 ?

Le travail local est accessible sans compte. L’agent local compatible doit être démarré pour enregistrer les projets ; la consultation de Mercurial nécessite Internet.

Quels sont les tarifs et les limites d’usage ?
